RASS + RassEngine

Role: Engineer, Game Designer, Artist

Overview

  • Engine / Tools: Custom C++ Engine (RassEngine), OpenGL, GLFW, FMOD, Visual Studio, Git
  • Core Focus: Building a high-performance, modular custom 2D game engine specializing in action-platformers, paired with complete gameplay implementation and level-building pipelines.
  • Architecture: Data-driven Entity-Component architecture featuring dependency injection, stream serialization, and archetype caching.

Key Technical & Architectural Contributions

  • Engine Subsystems: Architected foundational C++ game engine systems, including an Entity Factory utilizing archetype caching, Stream serialization, and a custom Memory Management system.
  • Professional Software Workflows: Facilitated professional development pipelines by organizing technical syncs, enforcing GitHub branching standards, executing rigorous code reviews, and managing pull request merges to ensure code portability and maintainability.
  • Cross-Functional Debugging: Read, analyzed, and debugged peer code across cross-functional subsystems, seamlessly integrating external physics handlers, input systems, and rendering queues under strict production schedules.
  • Runtime Utility Modules: Engineered critical modules from scratch, including a state-driven Animation Controller, a multi-level Logging System for diagnostics, and precise Timed Screen Transitions.

Gameplay Design & Artistry

  • Mechanics & Movement: Conceptualized, programmed, and iteratively refined signature gameplay features—including a custom-engineered Rocket Jump action and fluid player movement based on structured playtest feedback and genre research.
  • Level Design: Designed action-focused gameplay levels featuring deliberate pacing, difficulty scaling, and tilemap-driven layouts.
  • Asset Creation: Illustrated custom multi-layered 2D sprite sheets (idle, walk, jump animations), enemy sprites, UI branding, and level backgrounds from scratch using Aseprite.

Results & Takeaways

  • Successfully delivered a robust, data-driven custom 2D C++ game engine capable of running stable gameplay.
  • Shipped the project on-schedule under a rigorous timeline while balancing multiple disciplines.
