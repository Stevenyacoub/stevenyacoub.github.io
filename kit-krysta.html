Kit & Krysta: Krysta's Big Decision

Role: Lead Programmer, Artist

Overview

  • Engine / Tools: Unity, C#, Git, Visual Studio
  • Core Focus: A Famicom-inspired visual novel built in a one-month rapid development cycle, requiring high efficiency and rapid iteration.
  • Collaboration: Developed in close partnership with Kit Ellis (Production) and Dale North (Audio) to deliver an exciting birthday gift for Krysta Yang.

Key Technical Contributions

  • Dialogue Systems: Engineered a complex dialogue and branching decision tree system, integrating external graph libraries while implementing custom software design patterns for efficient data handling.
  • Cross-Platform Pipelines: Architected build systems for both PC and Mac, ensuring distinct OS-specific dependencies were handled to guarantee stability and performance on both platforms.
  • Technical Problem Solving: Translated external design documentation into functional logic within a 30-day production window, iterating rapidly based on stakeholder feedback.
  • Artistry: Authored all pixel art assets for the project, maintaining a cohesive Famicom aesthetic that aligned with the established design documentation.

Results & Takeaways

  • Successfully met all specifications within the condensed one-month development timeline, resulting in a feature-complete visual novel as a birthday present that was received very well.
  • Streamlined dialogue storage and node logic through custom C# design patterns, improving code maintainability for the project's branching narrative.
